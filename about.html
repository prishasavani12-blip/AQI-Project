About the Project

Air Quality Index

The Air Quality Index (AQI) project is a simple Python-based web application that helps users understand the quality of air.

Users can enter pollutant values such as PM2.5, PM10, CO, NO₂, SO₂ and O₃ to calculate an AQI value.

Project Features

  • AQI Calculator
  • AQI Category
  • Health Advice
  • Recent AQI Data
  • AQI Graph

Technologies Used

  • Python
  • Flask
  • HTML
  • CSS
  • Pandas
  • Matplotlib

Objective

The main objective of this project is to provide a simple and easy-to-understand way to view and analyze air quality information.
